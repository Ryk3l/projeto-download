# YouTube Media Downloader

Projeto desenvolvido com o objetivo de baixar vídeos e músicas para uso offline.

## Status do Projeto
A funcionalidade de download em MP3 está funcionando. No entanto, o download em MP4 não está funcionando corretamente devido às constantes verificações e travas de segurança do YT.

## Funcionamento

1. Ao executar o script pela primeira vez, ele cria automaticamente um arquivo chamado links.txt.
2. Os links dos vídeos do YT devem ser colocados dentro desse arquivo.
3. O script permite escolher o download nos formatos MP3 ou MP4.

## Tecnologias Utilizadas
- Python 3.x
- yt-dlp
